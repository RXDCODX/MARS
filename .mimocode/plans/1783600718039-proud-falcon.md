# Plan: Add audio playback to WaifuAlerts OBS component

## Goal
Play the waifu's custom audio track when it drops (in addition to the existing marriage audio).

## Current state
- `WaifuAlerts.tsx` already has an `<audio>` element for marriage (`svadba.mp3`) in the merge section (lines 440-464)
- `Waifu` interface has `audioId?: string` and `audio?: WaifuRollAudio`
- Audio streaming endpoint: `GET /api/WaifuRoll/audios/{id}/stream`

## Changes

### `WaifuAlerts.tsx`
Add a new `<audio>` element that plays when `currentMessage.waifu.audioId` is present and the alert is shown (not merged).

Location: Inside the alert box div (around line 273), add:
```tsx
{currentMessage.waifu.audioId && (
  <audio
    key={`waifu-audio-${currentMessage.waifu.shikiId}`}
    autoPlay
    controls={false}
    src={`${getApiBaseUrl()}/api/WaifuRoll/audios/${currentMessage.waifu.audioId}/stream`}
  />
)}
```

This plays the audio when the waifu image is shown. The audio plays once and stops automatically.
