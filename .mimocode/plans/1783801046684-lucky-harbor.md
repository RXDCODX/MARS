# MikuRoll — Implementation Plan

## Overview

Create a new "MikuRoll" Twitch channel point reward (like FumoRoll/FrogRoll) that rolls a random Hatsune Miku module (costume from Project DIVA). Data comes from `modules.json` (216 entries), images from `wwwroot/miku_monday/` (215 files). Active on **Mondays**, color **#39C5BB**, cost **4 points**.

---

## Backend (MARS.Server)

### 1. Entity — `MikuModule.cs`

**File**: `MARS.Projects/MARS.Server/Services/Twitch/Entitys/MikuModule.cs`

```csharp
[Table("MikuModules")]
public class MikuModule
{
    [Key]
    public int PageId { get; set; }  // from modules.json "pageid" — unique wiki ID

    [Required] [MaxLength(300)]
    public required string Title { get; set; }

    [MaxLength(300)]
    public string? JapaneseName { get; set; }

    [MaxLength(200)]
    public string? Designer { get; set; }

    [Required] [MaxLength(500)]
    public required string ThumbnailUrl { get; set; }  // "/miku_monday/{title}.{ext}"

    [MaxLength(2000)]
    public string? Description { get; set; }

    [MaxLength(500)]
    public string? Songs { get; set; }  // JSON array serialized as string

    public DateTimeOffset WhenAdded { get; set; }
    public DateTimeOffset LastOrder { get; set; }
    public int OrderCount { get; set; }
}
```

### 3. Service — `MikuModuleRollService.cs`

**File**: `MARS.Projects/MARS.Server/Services/Twitch/Rewards/4_MikuModuleRoll/MikuModuleRollService.cs`

Two methods (same pattern as `FumoRollService`/`FrogRollService`):
- `RollTheMikuModule()` — `OrderBy(LastOrder).FirstOrDefaultAsync()`, increment OrderCount, update LastOrder
- `GetMikuModulePrizesAsync()` — return all modules as `MikuModulePrizeType` list, `AsNoTracking()`

Uses `IDbContextFactory<AppDbContext>`.

### 4. Twitch Reward — `MikuModuleRoll_TwitchReward.cs`

**File**: `MARS.Projects/MARS.Server/Services/Twitch/Rewards/4_MikuModuleRoll/MikuModuleRoll_TwitchReward.cs`

Same pattern as `FumoFridayRoll_TwitchReward`/`FrogRoll_TwitchReward`:
- Inherits `TemporaryReward`
- `AlertDisplayName` = `"🎀 Miku Module Roulette"`
- `AlertDescription` = `"Крути рулетку костюмов Miku по понедельникам! ♪"`
- `Color` = `Color.FromArgb(57, 197, 187)` (#39C5BB)
- `Cost` = 4
- `IsRewardEnabled` = `() => DateTime.Now.DayOfWeek == DayOfWeek.Monday`
- On redemption: validates → rolls module → pushes `MikuModuleRoll` via SignalR

### 9. Migration — `AddMikuModules.cs`

**File**: `MARS.Projects/MARS.Server/Migrations/<timestamp>_AddMikuModules.cs`

Create table `MikuModules` with columns matching the entity. Seed all 216 entries from `modules.json`. For each entry:
- `PageId` = `pageid`
- `Title` = `title`
- `JapaneseName` = `japanese_name`
- `Designer` = `designer`
- `ThumbnailUrl` = `/miku_monday/{title}.{ext}` (derived from `local_image` field, replacing `module_images\` prefix)
- `Description` = `description` (truncated to 2000 chars if needed)
- `Songs` = JSON-serialized `songs` array
- `WhenAdded` / `LastOrder` = `DateTimeOffset.MinValue`
- `OrderCount` = 0

The migration will include a script/tool to generate the `InsertData` calls from `modules.json`.
