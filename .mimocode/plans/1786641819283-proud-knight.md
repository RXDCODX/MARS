## Этап 0: Синхронизация с master

Перед продолжением распиливания нужно влить 144 коммита из master.

### Стратегия: merge master в microservices
```bash
git checkout feature/microservices-architecture
git merge master --no-ff -m "merge: синхронизация с master (WaifuChat, DanbooruAutoPost, NSFWBooru, тесты)"
```

### Зоны конфликтов
| Файл | Риск | Действие |
|------|------|----------|
| MARS.sln | Высокий | Взять microservices + добавить проекты из master |
| MARS.Shared (сабмодуль) | Высокий | Оставить microservices (новый shared) |
| MARS.Server (сабмодуль) | Средний | Взять master (WaifuChat, DanbooruAutoPost) |
| MARS.Tests | Средний | Объединить тесты |
| Directory.Packages.props | Средний | Объединить пакеты |
| docker-compose.yml | Низкий | Взять microservices |

## Этап 2: Миграция автопостинга → MARS.AutoPost (порт 5015)

### Решение: отдельный сервис MARS.AutoPost
Для всех сервисов с автопостингом — единый микросервис.

### Что мигрировать

| Компонент | Исходный путь | Назначение |
|-----------|---------------|------------|
| DanbooruAutoPostService | Services/DanbooruAutoPost/ | Автопостинг Danbooru в Telegram |
| DanbooruAutoPostController | Controllers/ | API управления |
| DanbooruPost (модель) | Models/ | Модель поста |
| NSFWBooruAutoPostService | Services/NSFWBooru/ | Автопостинг Rule34 в Telegram |

### BooruShared → MARS.Shared (общая библиотека)

| Компонент | Назначение |
|-----------|------------|
| DeduplicationService | Дедупликация постов (нужна и AutoPost, и Alerts) |
| TagValidator | Валидация тегов (нужна и AutoPost, и Alerts) |

### Что НЕ мигрируется сюда
- `NSFWBooruRandomPostService` → MARS.Alerts (по запросу через награду, не автопостинг)

### Структура проекта
```
MARS.Projects/MARS.Microservices/MARS.AutoPost/
├── MARS.AutoPost.csproj (ссылка на MARS.Shared)
├── Program.cs
├── Dockerfile
├── appsettings.json
├── Controllers/
│   └── DanbooruAutoPostController.cs
├── Services/
│   ├── Danbooru/

│   │   └── DanbooruPost.cs
│   └── NSFWBooru/
│       └── NSFWBooruAutoPostService.cs

    └── AutoPostDbContext.cs (schema: `autopost`)
```

### Зависимости
- Telegram Bot API (отправка постов)

- RabbitMQ — события
