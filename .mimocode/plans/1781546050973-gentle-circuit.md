## Key Findings

### Alert Types & data-testid values
| Type | data-testid | Component |
|------|-------------|-----------|
| TelegramSticker | `pyro-alert-sticker` | TelegramSticker.tsx |
| Audio | `pyro-alert-audio` | Audio.tsx |
| Voice | `pyro-alert-voice` | Voice.tsx |
| LetterBox | (inside `pyro-alert-audio`) | BigTextBlockForAudio.tsx |

### API Endpoints
- `POST /api/TestAlerts/alert` - accepts full MediaDto body (needed for custom files)
- `POST /api/TestAlerts/alert-by-type` - auto-finds files from wwwroot (limited extension support)
- `TelegramSticker` is NOT supported by `alert-by-type` endpoint

### File Extension Support
- `alert-by-type` only finds: `*.mp3`, `*.wav` (Audio), `*.wav` (Voice)
- `.flac`, `.ogg`, `.tgs` files need `alert` endpoint with custom MediaDto

### Step 1: Add helper method to copy test files to wwwroot
Add a private helper to copy test files from `MARS.AutoTests/` to `MARS.Server/wwwroot/Alerts/`:

```csharp
private static void CopyTestFilesToServer()
{
    var repoRoot = AppSettingsHelper.FindRepoRoot();
    var sourceDir = Path.Combine(repoRoot, "MARS.Projects", "MARS.AutoTests");
    var targetDir = Path.Combine(repoRoot, "MARS.Projects", "MARS.Server", "wwwroot", "Alerts");
    
    Directory.CreateDirectory(targetDir);
    
    var filesToCopy = new[]
    {
        "1483493149.tgs",
        "Kanye West - Wolves.flac",
        "audio_2026-06-15_21-44-29.ogg"
    };
    
    foreach (var file in filesToCopy)
    {
        var source = Path.Combine(sourceDir, file);
        var target = Path.Combine(targetDir, file);
        if (File.Exists(source) && !File.Exists(target))
        {
            File.Copy(source, target);
        }
    }
}
```

### Step 3: Add helper method to create MediaDto
Add a helper to construct MediaDto objects for custom alerts:

```csharp
private static MediaDto CreateMediaDto(
    MediaType type,
    string filePath,
    int duration = 10,
    MediaAlertPriority priority = MediaAlertPriority.Normal,
    bool isShowLetterbox = false,
    string? text = null)
{
    var extension = Path.GetExtension(filePath).TrimStart('.');
    var fileName = Path.GetFileNameWithoutExtension(filePath);
    
    return new MediaDto(new MediaInfo
    {
        TextInfo = new MediaTextInfo { Text = text ?? string.Empty },
        FileInfo = new MediaFileInfo
        {
            Type = type,
            FilePath = $"Alerts/{filePath}",
            IsLocalFile = true,
            FileName = fileName,
            Extension = extension,
        },
        PositionInfo = new MediaPositionInfo
        {
            IsProportion = true,
            Width = 500,
            Height = 500,
            IsUseOriginalWidthAndHeight = true,
        },
        MetaInfo = new MediaMetaInfo
        {
            DisplayName = "TestUser",
            Duration = duration,
            Priority = priority,
            Volume = 100,
        },
        StylesInfo = new MediaStylesInfo
        {
            IsBorder = false,
            IsShowLetterbox = isShowLetterbox,
        },
    });
}
```
