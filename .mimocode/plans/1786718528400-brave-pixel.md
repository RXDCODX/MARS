# Исследование: Замена TTS движка Supertonic для MARS

## Статус: в процессе

---

## 1. Контекст

Текущая TTS система `MARS.AudioController` построена на ONNX моделях от **Supertone/supertonic**:
- 4 ONNX модели: `duration_predictor.onnx`, `text_encoder.onnx`, `vector_estimator.onnx`, `vocoder.onnx`
- 10 голосовых стилей (M1-M5, F1-F5) в формате JSON
- 31 язык, включая русский
- CPU inference через `Microsoft.ML.OnnxRuntime`
- 44100 Hz, 16-bit PCM output

**Проблема**: Supertonic архивируется (июль 2026), Voice Builder недоступен после авг 2026.

## 2. Обязательные требования

| # | Требование | Описание |
|---|-----------|----------|
| 1 | **Русский язык** | Качественная генерация русской речи |

| 3 | **Клонирование голоса** | Zero-shot или few-shot клонирование из аудио сэмпла |

## 4. Детальный анализ кандидатов

### 4.1 Coqui XTTS v2 — лучшее совпадение по функциям

**Плюсы:**
- ✅ Русский язык — один из 17 официально поддерживаемых
- ✅ CPU inference — выделенный Docker образ `ghcr.io/coqui-ai/tts-cpu`
- ✅ Клонирование голоса — всего 3-6 секунд референсного аудио
- ✅ Streaming <200ms latency
- ✅ 45.9k звёзд, зрелый проект

**Минусы:**
- ❌ Нет ONNX экспорта (issue #4391 закрыт как "wontfix")
- ❌ Нет C#/.NET интеграции — только Python
- ⚠️ Компания Coqui мертва (blog 404, 3 open issues)
- ⚠️ CPML лицензия — кастомная, требует юридической проверки
- ⚠️ Нужен Python HTTP API wrapper для .NET

**Интеграция с MARS:** Python-сервис (FastAPI) → HTTP API → .NET клиент

---

### 4.2 F5-TTS — лучший путь для ONNX/.NET

**Плюсы:**
- ✅ Flow-matching архитектура, zero-shot voice cloning
- ✅ ONNX порт от DakeQQ (206 stars, Apache-2.0)
- ✅ CPU support через OpenVINO/DirectML
- ✅ MIT лицензия кода
- ✅ Активная разработка (700 commits)
- ✅ Community модель для русского (HotDro4illa на Common Voice)

**Минусы:**
- ⚠️ Русский — неофициальная community модель, качество не проверено
- ⚠️ Претренированные модели — CC-BY-NC (некоммерческая)
- ⚠️ ONNX порт — third-party, не от оригинальных авторов
- ⚠️ Нет готового C# примера — нужен порт с Python ONNX Runtime кода
- ⚠️ Нужен Python для предобработки текста (токенизация)

**Интеграция с MARS:** ONNX модели → `Microsoft.ML.OnnxRuntime` в C# (аналогично текущей архитектуре)

---

### 4.3 Fish Speech S2 Pro — SOTA качество

**Плюсы:**
- ✅ 80+ языков, русский Tier 2
- ✅ 4B параметров, лучшее качество (SOTA benchmarks)
- ✅ 10-30 секунд для клонирования голоса
- ✅ 15,000+ expression tags
- ✅ 32.2k звёзд, активная разработка

**Минусы:**
- ❌ Требует GPU (SGLang/vLLM) — НЕ работает на CPU
- ❌ Нет ONNX экспорта
- ❌ Нет C#/.NET интеграции
- ⚠️ Fish Audio Research лицензия
- ⚠️ 4B параметров — очень тяжёлая модель

**Интеграция с MARS:** Невозможна без GPU

---

### 4.4 Piper TTS — самый быстрый CPU

**Плюсы:**
- ✅ Русский — 4 предтренированных голоса (denis, dmitri, irina, ruslan)
- ✅ Самый быстрый CPU inference (нативный ONNX Runtime)
- ✅ Простой деплой (pip install piper-tts)
- ✅ HTTP API, C/C++ lib, Python API

**Минусы:**
- ❌ НЕТ клонирования голоса — каждый голос требует отдельной модели
- ❌ Нет C#/.NET интеграции
- ⚠️ GPL-3.0 лицензия (был MIT, изменён при архивации)
- ⚠️ Проект архивирован (окт 2025), преемник piper1-gpl

**Интеграция с MARS:** HTTP API → .NET клиент, или C++ lib через P/Invoke

---

### 4.5 Bark — нативный русский

**Плюсы:**
- ✅ Русский язык нативно
- ✅ CPU inference (медленно)
- ✅ MIT лицензия
- ✅ 100+ предтренированных голосов

**Минусы:**
- ❌ НЕТ клонирования голоса
- ❌ Нет ONNX экспорта
- ❌ Нет C#/.NET интеграции
- ⚠️ Ограничение ~13-14 секунд на генерацию
- ⚠️ Медленный на CPU

**Интеграция с MARS:** Python HTTP API → .NET клиент

---

### 4.6 Silero TTS — лучший русский

**Плюсы:**
- ✅ Отличная поддержка русского (auto-stress, homographs, SSML)
- ✅ CPU inference (PyTorch JIT)
- ✅ Apache-2.0 лицензия
- ✅ Активный проект

**Минусы:**
- ❌ НЕТ клонирования голоса
- ❌ Нет ONNX экспорта (только PyTorch JIT .pt)
- ❌ Нет C#/.NET интеграции
- ⚠️ Нужна конвертация в ONNX через `torch.onnx.export`

**Интеграция с MARS:** Конвертация в ONNX (одноразовая) → `Microsoft.ML.OnnxRuntime` в C#

---

### 4.7 CosyVoice 3 (Alibaba) — лучшее качество + русский

**Плюсы:**
- ✅ 9 языков, включая русский (Tier 1: ZH/EN/JA, Tier 2: KO/DE/ES/FR/RU/IT)
- ✅ Zero-shot voice cloning, cross-lingual cloning
- ✅ Streaming, Bi-Streaming (latency ~150ms)
- ✅ Pronunciation inpainting (Pinyin, CMU phonemes)
- ✅ Apache-2.0 лицензия
- ✅ 22.8k звёзд, активная разработка (Alibaba)
- ✅ LLM-based архитектура (0.5B параметров)

**Минусы:**
- ❌ Требует GPU (PyTorch, vLLM) — НЕ работает на CPU
- ❌ Нет ONNX экспорта
- ❌ Нет C#/.NET интеграции
- ⚠️ Только Python SDK

**Интеграция с MARS:** Невозможна без GPU. Python HTTP API → .NET клиент (если есть GPU).

---

### 4.8 Qwen3-TTS (Alibaba) — новейший с voice design

**Плюсы:**
- ✅ 10 языков, включая русский (ZH/EN/JA/KO/DE/FR/RU/PT/ES/IT)
- ✅ Voice cloning (3 секунды референсного аудио)
- ✅ Voice design (создание голоса по текстовому описанию)
- ✅ Streaming (latency ~97ms)
- ✅ Instruct control (эмоции, тон, скорость)
- ✅ Apache-2.0 лицензия
- ✅ 12.9k звёзд, активная разработка (Alibaba)
- ✅ 0.6B и 1.7B модели

**Минусы:**
- ❌ Требует GPU (CUDA) — НЕ работает на CPU
- ❌ Нет ONNX экспорта
- ❌ Нет C#/.NET интеграции
- ⚠️ Только Python SDK (qwen-tts)
- ⚠️ Очень новый проект (13 commits)

**Интеграция с MARS:** Невозможна без GPU. Python HTTP API → .NET клиент (если есть GPU).

---

### 4.9 StyleTTS2 — лучшее качество клонирования

**Плюсы:**
- ✅ Отличное zero-shot voice cloning
- ✅ CPU inference возможно
- ✅ MIT лицензия

**Минусы:**
- ❌ Нет поддержки русского (нужен кастомный PL-BERT)
- ❌ Нет ONNX экспорта
- ❌ Нет C#/.NET интеграции
- ⚠️ Требует значительных инженерных усилий для русского

**Интеграция с MARS:** Невозможна без тренировки PL-BERT для русского

## 6. Рекомендуемые подходы

### Вариант A: Обновление до Supertonic 3 (рекомендуется)
- Обновить ONNX модели до Supertonic 3 (99M параметров, 31 язык, expression tags)
- Модели останутся на HuggingFace несмотря на архивацию репозитория
- Реализовать SuperTonicVoiceBuilder (пустой проект уже существует)
- Минимальные изменения в коде — та же архитектура

### Вариант B: F5-TTS через ONNX Runtime
- Использовать DakeQQ/F5-TTS-ONNX порт
- CPU inference через OpenVINO
- Zero-shot voice cloning из референсного аудио
- Нужен порт Python ONNX кода на C#

### Вариант C: Coqui XTTS v2 через Python-сервис
- Лучшее качество и функции
- Python FastAPI сервис → HTTP API → .NET клиент
- Риск: компания мертва, CPML лицензия

### Вариант D: Гибридный подход
- Piper для быстрого default TTS (русский, CPU)
- F5-TTS/XTTS для клонирования голоса по запросу
