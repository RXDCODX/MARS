# Plan: Feature Toggles для WaifuChat LLM и TTS

## Контекст

Пользователь хочет добавить возможность отключения через appsettings.json:
1. **WaifuChat LLM** — полное отключение
2. **TTS** — три уровня контроля:
   - Общий `Tts:Enabled` — отключает весь TTS (SyntheziaQueueManager + все движки)
   - `Tts:WindowsTts:Enabled` — отключает только Windows TTS (SystemSpeech)
   - `Tts:OnnxTts:Enabled` — отключает только ONNX TTS (Synthezia)

**Текущее состояние:**
- `WaifuChatOptions` уже имеет `Enabled` (строка 27), но **нигде не проверяется**
- TTS не имеет options-класса вообще
- `AudioControllerHubClientHostedService` уже принимает `WaifuLlmService?` и `WaifuChatClassifier?` как nullable (строка 41-42)

## Подход

Паттерн: **conditional DI registration** — если фича отключена, сервисы не регистрируются. Nullable параметры + null-проверки в потребителях.

```csharp
    }

    public class OnnxTtsSettings
    {
        public bool Enabled { get; set; } = true;
    }
}
```

## Шаг 4: Program.cs — conditional DI registration

### TTS (общий + движки):

```csharp
// TTS — configure options
builder.Services.Configure<TtsOptions>(
    builder.Configuration.GetSection(TtsOptions.SectionName));

var ttsSection = builder.Configuration.GetSection(TtsOptions.SectionName);
var ttsEnabled = ttsSection.GetValue<bool>("Enabled", true);

if (ttsEnabled)
{
    // Windows TTS — conditional
    var windowsTtsEnabled = ttsSection.GetSection("WindowsTts")
        .GetValue<bool>("Enabled", true);
    if (windowsTtsEnabled)
    {
        builder.Services.AddSingleton<SystemSpeechTtsPlaybackService>();
    }
    else
    {
        builder.Services.AddSingleton<SystemSpeechTtsPlaybackService?>(_ => null);
    }

    // ONNX TTS — conditional
    var onnxTtsEnabled = ttsSection.GetSection("OnnxTts")
        .GetValue<bool>("Enabled", true);
    if (onnxTtsEnabled)
    {
        builder.Services.AddSingleton<TtsPlaybackService>();
    }
    else
    {
        builder.Services.AddSingleton<TtsPlaybackService?>(_ => null);
    }

    // SyntheziaQueueManager работает всегда когда TTS включён
    builder.Services.AddSingleton<SyntheziaQueueManager>();
    builder.Services.AddSingleton<ISyntheziaQueueManager>(sp =>
        sp.GetRequiredService<SyntheziaQueueManager>());
    builder.Services.AddHostedService(sp =>
        sp.GetRequiredService<SyntheziaQueueManager>());
}
else
{
    // TTS полностью отключён — регистрируем null-заглушки
    builder.Services.AddSingleton<SystemSpeechTtsPlaybackService?>(_ => null);
    builder.Services.AddSingleton<TtsPlaybackService?>(_ => null);
    builder.Services.AddSingleton<ISyntheziaQueueManager, NoOpSyntheziaQueueManager>();
}
```

### WaifuChat (существующий `WaifuChatOptions.Enabled`):

```csharp
builder.Services.Configure<WaifuChatOptions>(
    builder.Configuration.GetSection(WaifuChatOptions.SectionName));

var waifuChatEnabled = builder.Configuration
    .GetSection(WaifuChatOptions.SectionName)
    .GetValue<bool>("Enabled", true);

if (waifuChatEnabled)
{
    builder.Services.AddSingleton<WaifuChatClassifier>();
    builder.Services.AddSingleton<WaifuLlmService>();
    builder.Services.AddSingleton<IWaifuLlmService>(sp =>
        sp.GetRequiredService<WaifuLlmService>());
    builder.Services.AddSingleton<IStreamStateProvider, DefaultStreamStateProvider>();
    builder.Services.AddHostedService<WaifuChatCleanupService>();
}
```

## Шаг 5: SyntheziaQueueManager — nullable движки

**Файл:** `Services/TTS/SyntheziaQueueManager.cs`

Изменения:
1. `SystemSpeechTtsPlaybackService` → `SystemSpeechTtsPlaybackService?`
2. `TtsPlaybackService` → `TtsPlaybackService?`

4. `BuildAvailableBindings()` — guards перед добавлением голосов каждого движка
5. `PlayLocallyAsync()` — guards перед вызовами каждого движка

## Шаг 7: SyntheziaQueueManager — использовать TtsOptions вместо IConfiguration

Сейчас `SyntheziaQueueManager` читает `Tts:VoiceStyles` через `IConfiguration`:
```csharp
private readonly List<string> _availableVoiceStyles =
    configuration.GetSection("Tts:VoiceStyles").Get<List<string>>() ?? [];
```

Заменить на `IOptions<TtsOptions>`:
```csharp
private readonly List<string> _availableVoiceStyles = ttsOptions.Value.VoiceStyles;
```
