# Plan: Увеличить текст на призах рулетки + TextFit

## Проблема
В `WaifuRoulettePrizeItem` текст призов рендерится как обычный `<span>` в `<figcaption>` с фиксированным `font-size: 14px`, `max-width: 160px` и `text-overflow: ellipsis`. Текст слишком мелкий и обрезается.

## Решение
Заменить `<span>` на `<Textfit>` из `react-textfit` (пакет уже установлен и широко используется в проекте).

## Изменения

### 1. `WaifuRoulettePrizeItem.tsx`
**Путь:** `MARS.Projects/mars.client/src/components/OBS_Components/WaifuAlerts/components/WaifuRoulettePrizeItem.tsx`

- Добавить импорт: `import { Textfit } from "react-textfit";`
- Заменить блок:
  ```tsx
  <figcaption className={styles.caption}>
    <span>{normalizedText}</span>
  </figcaption>
  ```
  на:
  ```tsx
  <figcaption className={styles.caption}>
    <Textfit mode="single" max={48} min={8}>
      {normalizedText}
    </Textfit>
  </figcaption>
  ```
- `mode="single"` — текст в одну строку, максимально заполняет доступную ширину
- `max={48}` — верхний предел размера шрифта (крупный)
- `min={8}` — нижний предел, чтобы текст точно поместился

### 2. `WaifuRoulettePrizeItem.module.scss`
**Путь:** `MARS.Projects/mars.client/src/components/OBS_Components/WaifuAlerts/components/WaifuRoulettePrizeItem.module.scss`

В `.caption`:
- Убрать `font-size: 14px` (TextFit сам управляет размером)
- Убрать `text-transform: uppercase` (не нужно для крупного текста)
- Заменить фиксированный `padding: 6px 12px` на `padding: 8px 16px` (чуть больше для крупного текста)

В `.caption span` → заменить на `.caption > div` (Textfit рендерит `<div>`):
- Убрать `max-width: 160px`, `white-space: nowrap`, `overflow: hidden`, `text-overflow: ellipsis`
- Заменить на `width: 100%; height: 100%;` чтобы TextFit мог заполнить пространство
