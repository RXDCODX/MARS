# Plan: Fix duplicate validation messages + integration tests

## Problem

When RXDCODX activates 1 reward (cost 134), 3 messages appear in chat:
1. `@RXDCODX,` (empty message)
2. `@RXDCODX, Подпишись на канал, чтобы использовать эту награду`
3. `@RXDCODX, Подпишись на канал, чтобы использовать эту награду`

## Root cause analysis

### Issue 1: MiniGamesManager — no RequireCost guard
**File:** `Services/Twitch/Rewards/MiniGamesManager.cs:61-65`

Subscribes to `ChannelPointsCustomRewardRedemptionAdd` with `RequireServiceActive` + `RequireFollower(loud)` but NO `RequireCost`. Fires for EVERY redemption. Non-follower gets error message.

**Fix:** Add cost pre-check before validation:
```csharp
var cost = args.Payload.Event.Reward.Cost;
if (cost is not (9 or 7 or 6))
    return;
```

### Issue 2: AllRefund_TwitchReward — dual subscription
**File:** `Services/Twitch/Rewards/99999_AllRefundService/AllRefund_TwitchReward.cs:61-62`

Two handlers subscribe to same event:
- `OnRewardActivation` — has `RequireFollower(loud=true)` + `RequireCost(Cost)` + sends announcement
- `OnChannelPointsCustomRewardRedemption` — has `RequireCost(Cost)` + handles refund

When non-follower activates AllRefund reward: both fire, both validate, `OnRewardActivation` sends announcement + error.

**Fix:** Remove `RequireFollower` from `OnRewardActivation` (it's the activation handler, not the user-facing one).

### Issue 3: Empty message `@RXDCODX,`
The `ValidateWithResponseAsync` only sends when `FirstError != null`, so the empty message comes from elsewhere. Most likely source: `AllRefund_TwitchReward.OnRewardActivation` sends announcement via `api.SendAnnouncementToMainTwitchAsync($"@{twEvent.UserName}, активировал @{AlertDisplayName}!...")`. If `AlertDisplayName` is empty, produces `@RXDCODX, активировал !...`. Need to verify during implementation.

**Action:** Check `AllRefund_TwitchReward.AlertDisplayName` value and all `SendAnnouncementToMainTwitchAsync` calls in redemption handlers.
