# Plan: Stryker Mutation Testing Quality Test

## Context

Проект MARS.Tests уже настроен для мутационного тестирования через Stryker (`stryker-config.json`, `run-stryker.ps1`), но нет автоматического теста, который проверяет, что мутационный score соответствует минимальному порогу. Нужно добавить такой тест.

## Changes

### 1. `stryker-config.json` — добавить `json` reporter

Текущий конфиг: `"reporters": ["html", "cleartext"]`

Нужно: `"reporters": ["html", "cleartext", "json"]`

Без `json` reporter Stryker не генерирует `mutation-report.json`, который нужен для парсинга результата тестом.

**File**: `MARS.Projects/MARS.Tests/stryker-config.json`

### 2. Новый файл: `MARS.Projects/MARS.Tests\Backend\MutationTestingQualityTests.cs`

xUnit тест, который:

1. Находит последнюю директорию отчёта Stryker в `StrykerOutput/`
2. Читает `mutation-report.json`
3. Парсит mutation score (гибко — поддерживает разные форматы JSON)
4. Assert: score >= 50%

**Threshold = 50%** — обоснование:
- Совпадает с `break` из текущего stryker-config.json
- Для проекта с 90+ тест-файлов это минимум качества
- Порог легко поднять по мере улучшения тестов

**Особенности теста:**
- Тест **пропускается** (не падает), если Stryker не был запущен и отчёт не найден — через `SkipUnless` флаг
- Тест может опционально запускать `dotnet stryker` если задан `STRYKER_RUN=1`
- Stryker выполняется 10-30 минут, поэтому по умолчанию только читает готовый отчёт

```csharp
[Fact]
public void MutationScore_MeetsMinimumThreshold()
{
    // 1. Если STRYKER_RUN=1 → запустить dotnet stryker
    // 2. Найти последний StrykerOutput/<timestamp>/mutation-report.json
    // 3. Если нет отчёта → skip
    // 4. Десериализовать score из JSON
    // 5. Assert score >= 50%
}
```

## Verification

1. `dotnet build MARS.Projects/MARS.Tests/MARS.Tests.csproj` — компилируется
2. `dotnet test MARS.Projects/MARS.Tests/MARS.Tests.csproj --filter "MutationScore"` — тест пропускается (нет отчёта)
3. Запустить `pwsh MARS.Projects/MARS.Tests/run-stryker.ps1` → после завершения тест проходит с score >= 50%
