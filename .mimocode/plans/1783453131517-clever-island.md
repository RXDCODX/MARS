# Plan: Frogs System (аналог Fumo)

## Цель
Создать полную систему "Frogs" по аналогии с "Fumo": таблица БД, бэкенд-сервис, Twitch reward, SignalR hub, OBS компонент на фронтенде.

## Источник данных
- `D:\VS\MARS\frogs\frogwatch_data.json` — 60 лягушек с метаданными (pid, common_name, scientific_name, family, russian_name, size, status, category, habits)
- `D:\VS\MARS\frogs\photos\` — 52 фото в формате `{pid}_{variation}.jpg` (у каждой лягушки ровно 1 фото)
- Фото копируются в `MARS.Server/wwwroot/frogs/`

## 1. Бэкенд: Entity

**Файл:** `MARS.Server/Services/Twitch/Entitys/Frog.cs`

```csharp
[Table("Frogs")]
public class Frog
{
    [Key] public int Pid { get; set; }
    [Required][MaxLength(200)] public required string CommonName { get; set; }
    [Required][MaxLength(200)] public required string ScientificName { get; set; }
    [MaxLength(100)] public string? Family { get; set; }
    [MaxLength(200)] public string? RussianName { get; set; }
    [Required][MaxLength(200)] public required string ThumbnailUrl { get; set; }
    [MaxLength(50)] public string? Size { get; set; }
    [MaxLength(100)] public string? Status { get; set; }
    [MaxLength(50)] public string? Category { get; set; }
    [MaxLength(500)] public string? Habits { get; set; }
    public DateTimeOffset WhenAdded { get; set; }
    public DateTimeOffset LastOrder { get; set; }
    public int OrderCount { get; set; }
}
```

## 2. Бэкенд: PrizeType DTO

**Файл:** `MARS.Server/Services/Twitch/Entitys/FrogPrizeType.cs`

Аналог `FumoPrizeType` —轻量 DTO для рулетки:
- `int Id` (= Pid)
- `string Image` (= ThumbnailUrl)
- `string Text` (= CommonName)

## 3. Бэкенд: RollService

**Файл:** `MARS.Server/Services/Twitch/Rewards/5_FrogRoll/FrogRollService.cs`

Аналог `FumoRollService`:
- `RollTheFrog()` — выбирает лягушку с самым старым `LastOrder`, инкрементирует `OrderCount`, обновляет `LastOrder`
- `GetFrogPrizesAsync()` — возвращает все лягушки как `ICollection<FrogPrizeType>` для рулетки

## 4. Бэкенд: Twitch Reward

**Файл:** `MARS.Server/Services/Twitch/Rewards/5_FrogRoll/FrogRoll_TwitchReward.cs`

Аналог `FumoFridayRoll_TwitchReward`:
- Расширяет `TemporaryReward`
- `AlertDisplayName` = "🐸 Frog Roulette"
- `Cost` = 4 (или другой баланс)
- `IsRewardEnabled` = `() => true` (доступен всегда, или по расписанию)
- При redemption: вызывает `FrogRollService.RollTheFrog()`, затем `hubContext.Clients.All.FrogRoll(frog, user)`

## 5. Бэкенд: DbSet в AppDbContext

**Файл:** `MARS.Server/DataBaseContext/AppDbContext.cs`

Добавить: `public DbSet<Frog> Frogs { get; set; } = null!;`

## 6. Бэкенд: SignalR Hub

**Файл:** `MARS.Server/Hubs/Interfaces/ITelegramusHub.cs`

Добавить методы:
```csharp
[SignalRMethod]
public Task FrogRoll(Frog frog, TwitchUser twitchUser, string? color = null);

[SignalRMethod]
public Task UpdateFrogPrizes(ICollection<FrogPrizeType> prizes);
```

**Файл:** `MARS.Server/Hubs/TelegramusHub.cs`

- Инжектить `FrogRollService`
- В `OnConnectedAsync()`: вызвать `frogRollService.GetFrogPrizesAsync()` и отправить `UpdateFrogPrizes` caller-у

## 7. Бэкенд: DI регистрация

**Файл:** `MARS.Server/StartupExstensions.cs`

Добавить:
```csharp
// Frog services
services.AddSingleton<FrogRollService>();
services.AddSingleton<FrogRoll_TwitchReward>();
services.AddHostedService(sp => sp.GetRequiredService<FrogRoll_TwitchReward>());
```

## 8. Миграция

Создать EF Core миграцию через `dotnet ef migrations add AddFrogs`. Миграция включает:
- Создание таблицы `Frogs`
- `InsertData` с 52 лягушками (все фото из `frogs/photos/`)
- ThumbnailUrl = `/frogs/{filename}` (например, `/frogs/1_1.jpg`)

Данные для InsertData берутся из `frogwatch_data.json` + список файлов в `frogs/photos/`.
