# Plan: Smart Placement + Screen Bounds for Random PyroAlerts

## Problem

Two issues with `randomCoordinates: true` alerts:

1. **Screen overflow**: Text below media can extend beyond the viewport bottom. `getCoordinates` only accounts for media element dimensions, not the full container (media + text + gap).
2. **No collision avoidance**: Multiple random alerts overlap arbitrarily. No mechanism to find free screen space or manage overlapping alerts.

## Scope

Both features apply **only** to alerts with `positionInfo.randomCoordinates === true`.

---

## Feature 1: Constrain to Screen Bounds

**Goal**: The entire alert container (media + text) must not extend beyond `window.innerWidth` x `window.innerHeight`.

### Approach: Post-render bounds adjustment

The challenge is that `getCoordinates` is called before Textfit measures the text. So we use a two-phase approach:

1. Phase 1: Initial positioning via `getCoordinates` (existing behavior)
2. Phase 2: After render, measure the full container dimensions via `useRef` + `ResizeObserver`, and clamp position if needed

### Files to modify

#### `Primitive/Image.tsx`

- Add `containerRef` to the `imageContainer` div (replace existing `reference` ref or add a second ref)
- After the container becomes visible (`visibility: visible`), start a `ResizeObserver` on the container
- On each size change, if `randomCoordinates` is true:
  - Get container's `getBoundingClientRect()`
  - If `rect.right > window.innerWidth` → adjust `left` to `window.innerWidth - rect.width`
  - If `rect.bottom > window.innerHeight` → adjust `top` to `window.innerHeight - rect.height`
  - If `rect.left < 0` → adjust `left` to `0`
  - If `rect.top < 0` → adjust `top` to `0`
- Apply adjustments to `containerStyle` state

#### `Primitive/Video.tsx`

- Add a `containerRef` on the root `<div>` (the `styles.media` element)
- After `onLoadedMetadata`, start a `ResizeObserver`
- Same bounds-clamping logic as Image.tsx, but only for `randomCoordinates === true`
- Apply adjustments to `baseStyles` state

#### `Primitive/TelegramSticker.tsx`

- Add a `containerRef` on the root `<div>` (already has `elementReference`)
- After coordinates are set in `useEffect`, start a `ResizeObserver`
- Same bounds-clamping logic
- Apply adjustments to `style` state

#### `Primitive/Media.module.scss`

No changes needed — the existing styles are sufficient.

## Feature 2: Smart Placement (Collision Avoidance)

**Goal**: When a new `randomCoordinates: true` alert arrives, find an uncovered area on screen. If none exists, place it on top of the alert closest to death (smallest remaining duration). New alert overlays on top (higher z-index).

### Architecture: Zustand store + placement algorithm

#### New file: `src/shared/stores/alertPlacementStore.ts`

Zustand store tracking active alerts for placement decisions.

```typescript
interface AlertBounds {
  id: string;
  x: number;
  y: number;
  width: number;
  height: number;
  remainingTime: number;    // seconds left
  totalDuration: number;    // original duration
  registeredAt: number;     // Date.now()
}

interface AlertPlacementState {
  activeAlerts: AlertBounds[];
  registerAlert: (bounds: AlertBounds) => void;
  unregisterAlert: (id: string) => void;
  updateAlertBounds: (id: string, bounds: Partial<AlertBounds>) => void;
  updateRemainingTime: (id: string, remaining: number) => void;
  findFreeSpace: (width: number, height: number) => { x: number; y: number } | null;
  findClosestToDeath: () => AlertBounds | null;
}
```

**`findFreeSpace(width, height)`** algorithm:
1. Define a grid of candidate positions (e.g., every 50px across the viewport)
2. For each candidate `(x, y)`:
   - Check if the rectangle `(x, y, x+width, y+height)` overlaps any existing alert
   - If no overlap and within viewport bounds → return this position
3. If no free position found → return `null`

**`findClosestToDeath()`**:
1. Sort `activeAlerts` by `remainingTime` ascending
2. Return the one with smallest `remainingTime`

#### Modification: `src/shared/Utils/index.ts` — `getCoordinates`

When `randomCoordinates` is true:
1. Import `useAlertPlacementStore` — but `getCoordinates` is a plain function, not a hook
2. Instead: accept an optional `placementStore` parameter (the store's `getState()`)
3. Call `findFreeSpace(elementWidth, elementHeight)` to get position
4. If `null` (no free space), call `findClosestToDeath()` and return its `(x, y)` position
5. Fallback to random if store is not provided

```typescript
export function getCoordinates(
  reference: HTMLImageElement | HTMLVideoElement | HTMLDivElement,
  info: MediaInfo,
  isInWindow: boolean = true,
  placementStore?: { findFreeSpace: ..., findClosestToDeath: ... }
): React.CSSProperties {
  // ... existing code ...
  
  if (positionInfo.randomCoordinates) {
    if (placementStore) {
      const freeSpace = placementStore.findFreeSpace(elementWidth, elementHeight);
      if (freeSpace) {
        return { left: `${freeSpace.x}px`, top: `${freeSpace.y}px`, position: "absolute" };
      }
      // No free space — find closest to death
      const closest = placementStore.findClosestToDeath();
      if (closest) {
        return { left: `${closest.x}px`, top: `${closest.y}px`, position: "absolute", zIndex: 10 };
      }
    }
    // Fallback: random (existing behavior)
    // ...
  }
}
```

#### Modification: `Primitive/Image.tsx`

1. Import `useAlertPlacementStore`
2. On mount (when coordinates are set): call `registerAlert()` with the container's bounding rect and `metaInfo.duration`
3. On unmount: call `unregisterAlert()`
4. On each render where bounds change: call `updateAlertBounds()`
5. Pass `useAlertPlacementStore.getState()` to `getCoordinates()`
6. Start a timer that calls `updateRemainingTime()` every second

#### Modification: `Primitive/Video.tsx`

Same pattern as Image.tsx:
1. Import store
2. Register on `onLoadedMetadata` (when positioned)
3. Unregister on unmount
4. Update bounds on resize
5. Pass store to `getCoordinates()`

#### Modification: `Primitive/TelegramSticker.tsx`

Same pattern as Image.tsx:
1. Import store
2. Register in the positioning `useEffect`
3. Unregister on unmount
4. Update bounds on resize
5. Pass store to `getCoordinates()`
