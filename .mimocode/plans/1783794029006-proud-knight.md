# Plan: Fix CI workflows + MARS.Tests compilation errors

## Проблемы

1. **Node 20 deprecated** — GitHub Actions выводит deprecation warning, Node 20 будет удалён
2. **Нет recursive checkout** — сабмодули (MARS.Server, mars.client, MARS.AudioController) не чекаутятся → ошибки сборки
3. **Cache path не найден** — `MARS.Projects/mars.client/yarn.lock` недоступен без чекаута сабмодуля
4. **MARS.Tests не компилируется** — 2 файла передают 10 аргументов в конструктор, который теперь принимает 12

## Fix 1: Workflows — recursive checkout + Node 22

### `mars-tests-ci.yml`
```yaml
- name: Checkout code
  uses: actions/checkout@v4
  with:
    submodules: recursive
```

### `mars-autotests-ci.yml`
```yaml
env:
  NODE_VERSION: "22.x"    # было "20.x"

- name: Checkout code
  uses: actions/checkout@v4
  with:
    submodules: recursive
```

После `submodules: recursive` mars.client будет доступен → cache path `MARS.Projects/mars.client/yarn.lock` найдётся.
