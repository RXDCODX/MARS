# ADHD: перманентный toggle + таймер от 0 вверх

## Контекст

Текущее поведение: команда `adhd <seconds>` активирует оверлей на N секунд, таймер считает вниз от N до 0, потом взрыв и скрытие.

Нужно: если параметр не указан (`adhd`) — перманентное включение/выключение оверлея (toggle). Таймер всегда считает от 0 вверх.

## Файлы для изменения

### 1. Бэкенд — `MARS.Server/Hubs/Interfaces/ITelegramusHub.cs` (строка 53)

**Было:** `Task Adhd(int seconds);`
**Стало:** `Task Adhd(int? seconds);`

Сделать параметр nullable. Вызовы с числом работают как раньше (timed mode). Вызов с `null` = toggle permanent mode.

### 2. Бэкенд — `MARS.Server/Services/CommandExecutor/Commands/adhd_command.cs`

- Параметр `seconds` → `Required = false`
- Если параметр не указан → `await alertsHub.Clients.All.Adhd(null);` (toggle permanent)
- Если параметр указан → валидация + `await alertsHub.Clients.All.Adhd(seconds);` (timed)
- Описание команды обновить

### 3. Фронтенд — `mars.client/src/components/OBS_Components/ADHDLayout/ADHDController.tsx`

Полный рефактор логики:

**State:**
```typescript
interface ADHDState {
  isVisible: boolean;
  duration: number;       // 0 = permanent mode
  elapsedTime: number;    // считает от 0 вверх
  isPermanent: boolean;
}
```

**Actions:**
- `SHOW` — timed mode (seconds > 0): `isVisible=true, duration=seconds, elapsedTime=0, isPermanent=false`
- `SHOW_PERMANENT` — permanent mode (seconds=null): `isVisible=true, duration=0, elapsedTime=0, isPermanent=true`. Если уже visible+permanent → `HIDE` (toggle off)
- `HIDE` — сброс в initialState
- `TICK` — `elapsedTime + 1`

**handleMessage(seconds):**
- `seconds == null || undefined` → dispatch `SHOW_PERMANENT` (toggle)
- `seconds > 0` → dispatch `SHOW` (timed)

**Timer effect:**
- Если isVisible → `setInterval(TICK, 1000)` (всегда считает вверх)
- Если `!isPermanent && elapsedTime >= duration` → ExplosionGo + HIDE через 2 сек
- Если `isPermanent` → никогда не взрывается и не скрывается

**Убрать:**
- `pendingExtensions` логику (для permanent toggle не нужна очередь продлений; для timed режима — при новом timed вызове пока isVisible просто обновляем duration)
- `remainingTime` — заменён на `elapsedTime`

**Таймер в JSX:**
- `{formatTime(state.elapsedTime)}` вместо `{formatTime(state.remainingTime)}`

Запустить:

cd MARS.Projects/mars.client && yarn build:api

## Важные детали

- `Adhd()` — **server-to-client push only**, в `TelegramusHub` нет серверного обработчика. Меняем только интерфейс `ITelegramusHub` и клиент.
- Twitch reward (`AdhdSuperpower_TwitchReward`) передаёт `Adhd(60)` — не затрагивается, т.к. передаёт non-null int.
- OpenAPI spec (`swagger_hubs.json`) обновится автоматически при `--generate-openapi`.
- При timed режиме + повторный `adhd 30` → сброс таймера на новый (не EXTEND).
- При timed режиме + `adhd` (без параметра) → переключение в permanent.
- При permanent + `adhd` (без параметра) → выключение (toggle).
- При permanent + `adhd 30` → переключение в timed на 30 сек.

## Верификация

1. `dotnet build MARS.sln` — компиляция без ошибок
2. `yarn type-check` в mars.client — типы в порядке
3. Ручная проверка:
   - `adhd 30` → оверлей включается, таймер от 0:00 до 0:30, потом взрыв и скрытие
   - `adhd` → оверлей включается, таймер от 0:00 считает вверх бесконечно
   - `adhd` (повторно) → оверлей выключается
   - `adhd 30` потом `adhd` (без параметра) → переключение в permanent режим
