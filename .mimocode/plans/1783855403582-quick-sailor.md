## Feature 7: Separate DB Transactions

Collection writes use a **separate `DbContext`** instance from roll writes. Pattern:

```csharp
// Transaction 1: Roll (existing)
var module = await service.RollTheMikuModule(userId, cooldown);

// Transaction 2: Collection (separate DbContext via factory)
try {
    var stats = await collectionService.RecordRollAsync(userId, module.PageId);
} catch (Exception ex) {
    logger.LogWarning(ex, "Collection failed, roll still succeeds");
}

// SignalR broadcast with stats
await hubContext.Clients.All.MikuRoll(new MikuRollResult(module, user, stats));
```

No new migration — this is an architectural pattern applied to Features 4/6.

## Feature 4: Miku Costume Collection

**New entity:** `MARS.Server/Services/Twitch/Entities/UserMikuCollection.cs`

```csharp
[Table("UserMikuCollections")]
public class UserMikuCollection {
    public Guid Id { get; set; }
    public required string TwitchUserId { get; set; }  // FK TwitchUser
    public int MikuPageId { get; set; }                 // FK MikuModule
    public int Count { get; set; }
    public DateTime FirstObtained { get; set; }
    public DateTime LastObtained { get; set; }
}
// Unique index on (TwitchUserId, MikuPageId)
```

**New service:** `MARS.Server/Services/Twitch/Rewards/4_MikuModuleRoll/MikuCollectionService.cs`

```csharp
public class MikuCollectionService(IDbContextFactory<AppDbContext> factory) {
    public async Task<OperationResult<CollectionStats>> RecordRollAsync(
        string twitchUserId, int mikuPageId);
    public async Task<(int collected, int total)> GetUserCollectionStatsAsync(
        string twitchUserId);
    public async Task<int?> CheckGuaranteeAsync(string twitchUserId);
}

public record CollectionStats {
    public int CollectedCount, TotalCount, ThisModuleCount;
    public bool IsNew, GuaranteeTriggered;
    public int? GuaranteedPageId;
}
```

**Guarantee rules:**
- 5 copies of same module → 1 guaranteed new module
- 20 unique modules → 1 guaranteed new module

**Modify:**
- `AppDbContext.cs` — add `DbSet<UserMikuCollection>`
- `MikuModuleRoll_TwitchReward.cs` — after roll, call collection service (separate transaction)
- `ITelegramusHub.cs` — update `MikuRoll` signature to include stats

**New DTO:** `MARS.Server/Hubs/Models/MikuRollResult.cs`

```csharp
public record MikuRollResult(
    MikuModule Module, TwitchUser User,
    int CollectedCount, int TotalCount, string? Color);
```

**Migration:** New EF migration for `UserMikuCollections`.
