# Документация MARS

Документы разделены по назначению: инструкции по текущей реализации, операционные руководства и исторические материалы миграции.

## Текущая архитектура и разработка

| Документ | Назначение |
|---|---|
| [Межсервисные события: Wolverine + RabbitMQ](messaging-wolverine.md) | Контракты, reflection discovery, публикация через `IMessageBus`, listener-классы, exchange/queue, DLQ, конфигурация и тесты |
| [Mutation testing](mutation-testing.md) | Запуск и анализ mutation-тестов |

## Media Storage

| Документ | Назначение |

## История миграции из MARS_old

| Документ | Назначение |
|---|---|
| [Чеклист миграции сервисов](SERVICE_MIGRATION_CHECKLIST.md) | Сопоставление компонентов монолита с результатами переноса |
| [Матрица миграции](SERVICE_MATRIX.md) | Производная сводка по чеклисту |
| [Вопросы миграции](MIGRATION_QUESTIONS.md) | Вопросы и варианты решений, зафиксированные в ходе переноса |

Эти три файла — исторические артефакты миграции, а не описание текущего runtime. Некоторые названия и пути в них намеренно относятся к исходному монолиту. Перед выполнением старого пункта проверяйте, не изменилось ли состояние в `src/` и последующих PR.

## Планы

В `plans/` находятся проектные заметки и предложения. Они не считаются реализованными требованиями, пока соответствующие изменения не появились в коде.
