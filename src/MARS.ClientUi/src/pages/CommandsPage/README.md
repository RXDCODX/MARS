# CommandsPage - Новая страница команд

Современная страница для выполнения команд системы MARS с улучшенным дизайном и архитектурой.

## 🚀 Новые возможности

### Современный дизайн

- **Иконки Lucide React** - красивые векторные иконки для всех элементов
- **Анимации и переходы** - плавные анимации при наведении и взаимодействии
- **Улучшенная типографика** - современные шрифты и размеры
- **Адаптивный дизайн** - оптимизация для всех устройств

### Улучшенная архитектура

- **SOLID принципы** - каждый компонент имеет одну ответственность
- **Разделение компонентов** - логика разделена на отдельные компоненты
- **Типизация TypeScript** - строгая типизация для всех пропсов и состояний
- **Хуки React** - использование современных React паттернов

## 🏗️ Архитектура компонентов

### Основные компоненты

#### 1. CommandsPage (главный компонент)

- Управление состоянием приложения
- Координация между компонентами
- Обработка API вызовов

#### 2. ListView

- Отображение команд в виде списка
- Подробная информация о каждой команде
- Интерактивные карточки с анимациями

#### 3. GridView

- Отображение команд в виде сетки 3x3
- Компактные карточки с иконками
- Адаптивная сетка для разных экранов

#### 4. CommandParameters

- Панель настройки параметров команды
- Динамические поля ввода по типу параметра
- Валидация и обработка ошибок

#### 5. CommandSearch

- Поиск команд по названию и описанию
- Счетчик найденных результатов
- Быстрая очистка поиска

#### 6. DisplayModeToggle

- Переключение между режимами отображения
- Анимированные кнопки с иконками
- Сохранение выбранного режима

## 🔧 Технические особенности

### Состояние приложения

```typescript
interface CommandsPageState {
  userCommands: CommandInfo[];
  adminCommands: CommandInfo[];
  selectedCommand: CommandInfo | null;
  commandParameters: CommandParameterInfo[];
  parameterValues: Record<string, string>;
  isExecuting: boolean;
  error: string;
  isLoading: boolean;
  activeTab: "user" | "admin";
  displayMode: "list" | "grid";
  searchQuery: string;
  showParameters: boolean; // Новое поле для управления панелью параметров
}
```

### API интеграция

- Использование `CommandsService` для работы с API
- Обработка ошибок через toast уведомления
- Асинхронная загрузка команд и параметров

### Toast уведомления

- Интеграция с `useToastModal`
- Показ результатов выполнения команд
- Обработка ошибок с детальной информацией

## 🛠️ Установка и использование

### Зависимости

```bash

```

### Импорт

```typescript

```

### Использование в роутере

```typescript

```
